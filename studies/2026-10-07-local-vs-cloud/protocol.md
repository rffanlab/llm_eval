# 本地与官方 Flash：工作交付差距评测 v2.0

冻结日期：2026-10-07（Asia/Shanghai）。原始题库和评分器先提交 Git，再发起正式请求。

## 一、为什么做

要决定的是：137 的本地配置能否承担日常代码、Agent 和写作工作，在哪些任务上能接受与官方服务的差距，哪些环节仍需官方服务或人工兜底。评价对象是完整运行配置，不预设本地与云端同权重、同精度，也不预设本地一定更差。

## 二、怎么做

- 本地：Ryzen AI Max+ 395 / Radeon 8060S，128 GB 统一内存；Ubuntu 24.04.5、Linux 7.0.0-31；Halogen 0.9.1，HGN W4B 与质量侧车，MTP、256K、单 slot。正式运行前另存脱敏健康信息。无引擎升级或参数调优后择优报分。
- 官方：阿里云 Token Plan，北京，模型 ID `qwen3.8-flash`。这不是千问网页产品。返回的 alias 不等于可追溯的权重 revision。
- 同一 system、题面、工具 schema、输出预算、temperature=0、思考开启（enable_thinking=true）；不使用 JSON constrained decoding，不追加纠错。若某端拒绝字段，记录兼容性失败后另立运行配置，不能静默去掉。
- 10 道题：基础结构化、基础代码、基础写作；中级状态归并、Agent 预留、证据写作；复杂调度代码、Agent 故障恢复、长材料联查、决策写作。难度由约束数量与工作步骤界定，不是假称的标准考试难度。
- 每题先一组配对；预先指定 C03、A02、E01 再各重复两组，共 32 个任务会话。重复使用相同题面，表示运行重复性，不增加独立题目数。两端先后交替；串行执行，避免本地资源争抢。每个任务启动前由本对话人工代理发起并检查，不用 Token Plan 无人值守批量调用。
- 每个 Agent 会话最多 6 次模型轮次、累计输出预算 8192 token；只允许固定的合成工具，禁止执行真实外部动作。工具返回、错误、恢复、越权尝试完整保存。直接任务输出预算在题库明示；不因某方截断临时追加预算。
- 超时：单次 HTTP 240 秒；代码测试子进程 5 秒。HTTP/格式/截断均保留，失败不自动重跑。会话先后、原始时间、TTFT（若可得）、完整交付墙钟、usage、finish_reason 分开保存。completion/全墙钟是端到端产出率，不叫纯解码速度。
- 规划上限：32 会话，直接题预算约 12 万输出 token 上限，Agent 纳入每会话 8192 总上限；含长材料的输入预计约 15–25 万 token，最终只以返回 usage 核对。达到 40 万总 token 暂停审查。中文字符数不冒充 tokenizer 计数。

### 评分

- D01/E01：合法 JSON、精确字段和值、来源 ID，等权评分；全对才算硬验收。
- C01/C02/C03：交付指定纯 Python 函数；独立测试的通过比例给分，全部测试通过且满足安全执行约束才算硬验收。测试包含空输入、边界、错误输入和顺序扰动；任务不给参考解。
- A01/A02：工具选择与参数、状态变化/重试、事实回答、权限遵守分别核验；重复写入和越权动作是关键失败。模拟器不执行真实采购、重启或删除。
- W01/W02/W03：硬规则（字数、指定事实/出处、格式）独立计分；另将输出匿名化，对事实忠实、信息完整、结构清晰、可用性各 0–5 分，合计 20 分。此为编辑代理复核，不冒充人工用户盲评；人工听审/文案确认另记。是否直接发布不能由字符匹配决定。
- 额外维度：延迟、token 用量、工具轮次、完整交付、截断、错误、干预次数；不混成一个任意加权排行榜。

### “差距可忽略”的事前边界

仅可按本组任务、按领域给条件性判断：本地所有关键硬约束通过，客观得分至少 90/100，落后官方不超过 5 分；写作编辑复核至少 16/20 且差距不超过 2 分；短任务完整交付不超过 60 秒，复杂任务不超过 240 秒；无额外人工修正和越权。任何一个不满足，都不得写该领域差距可忽略。

这些是本项目的业务容忍线，不是统计等效性证明。每领域独立题目不足，重复三次也不能证明长期可靠。若两方都错，不能因为差值为零就判“本地胜任”。

## 三、结果怎么呈现

每题说明任务内容和难度，随即展示两端输出、评分与关键差距；先解释失败实例，再汇总领域结论和能接什么工作。公开题库、评分代码、测试用例、配置快照、原始回复及运行命令；不发布密钥、内网凭据或私人材料。公众号与视频使用同一证据表。没有完成实测的项目显示未测，不用旧结果补齐。
